# Categories as references

**Every phrase lives in Library, and a category is a list of references to Library phrases**, in an order of its own. There is no All tab: Library shows every phrase, so All had nothing left to do, and Library took its place, pinned second after Sent. A phrase can be in any number of categories, or in none — it is in Library whatever.

- **`PhraseStore.members`** is the whole of a category: its name, and the ids of the Library phrases it refers to, **in its order**. That order is the category's Custom order; A to Z, Most used and Recently used are still offered on a category, as they are on Library. A category with no references is an empty list, kept so one can be made first and filled afterwards. **Library's own order is `libraryOrder`**, and Library is not in `members`: it holds every phrase and is never a list of some of them.
- **A phrase somebody writes lives in Library** — `StoredPhrase.category` is Library, or Emergency for a button on the bar. The emergency bar is still its own place: its phrases are not in Library and are in no category.
- **Library is not a category somebody made.** It is pinned, cannot be renamed, deleted or moved among the tabs, and the pencil says why. `allCategories` is the categories people made; Library is added as a tab of its own in `talk.tsx`.
- **The editor ticks categories rather than choosing one.** `CategoryPicker` is multi-select, held until Done like every grid with Done and Cancel (`ui/pending-choice.ts`) — **as one string, the names joined**, because a list is a new array every render and the hook tells a change by comparing. Ticking none is a phrase in Library alone, and the trigger says *Library only*. A new phrase written on a category starts with it ticked; on Library, Sent, the answers or Translations the last choice stands, as it did for All.
- **The bin on a category takes the phrase out of it; on Library it deletes.** Out of a category, the phrase is still in Library and in any other category, with its count. Deleted, it goes from Library and from every category that referred to it. `removePhrase(id, from)` hands back a `Removed` carrying every reference it took and every category it emptied, with where each stood, so an undo puts all of it back in place. The bin's label says which: *Take out of Food*, or *Delete phrase*.
- **Deleting a category deletes nothing anybody said.** Its phrases stay in Library and in any other category they are in; the question before it says so. A category the last reference leaves goes by itself — see [Editing a phrase](editing-a-phrase.md).
- **The same wording is in Library once**, so the duplicate guard asks Library — or the bar, for a phrase going there — and which categories are ticked makes no difference. Typing searches Library, which is now every phrase on the board.
- **A board from before was filed, and is read into references** — `fromFiled` in `core/store/phrase-store.ts`. Every phrase goes to Library; each one filed under another category — its own, one it was moved to, or the name a rename showed — is referred to by it, in the order the tab showed (its arrangement, then the board's), so nothing on any tab moves. A category somebody made and left empty stays. A store is told apart by having `members`, and stamped `table: 3` when saved.
- **Backups are at version 2** and carry `members` and `libraryOrder`. A file at version 1 filed each phrase under a category, and `parseBackup` reads it into references the same way (`fromVersion1`); what it renamed is not read, every name it renamed having been a category Peri used to ship. A file covering a few categories carries the phrases they refer to; one covering Library carries every phrase and Library's order. Merging appends a file's references behind a category's own, and **a phrase already here by its wording is the one the file's categories refer to**, rather than a second copy.
- **A spreadsheet is one row a phrase**: *Categories, Phrase, ID*, the first cell listing the categories that refer to it, separated by semicolons — Emergency for the bar, and nothing for Library alone. **The row order is not read for a category's order**: a category keeps its own, and what a sheet puts in it goes on its end. Adding never takes a phrase out of a category; replacing makes each category hold what the sheet says and takes away one no row names. A sheet from before, with a single category a row, reads as one naming that category.
- **This was a major release**: All is gone, and a backup written now cannot be read by a release before it.
