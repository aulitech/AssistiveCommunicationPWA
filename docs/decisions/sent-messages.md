# Sent messages

> One of the decisions behind Peri, moved out of [AGENTS.md](../../AGENTS.md), which keeps the map of
> the source and the rules that hold everywhere. What is written here is why the code is the shape it is.

**Every message spoken or copied is kept in Library**, as a phrase of its own, unless Library says it already — **and in the category whose tab is showing**, where Save would file it, so a sentence said on a tab is on that tab afterwards. Said on Library or a record, it is in no category. There used to be a **Sent** tab for this, pinned first: a list of what had been said, newest first, under a key of its own. Now that every phrase lives in Library and typing searches it, a second place to find a sentence said before was a second place to look. So what is said goes where everything else is, and is found the way everything else is.

- **Kept by `keepSaid` in `talk/use-board.ts`**, and the rule is `keepingSaid` in `core/board.ts`: the message trimmed, and left out if it is empty or Library already has that wording — the duplicate guard's `wordingKey`, so case and spaces make no difference and a phrase somebody deleted does not count. The emergency bar is not Library, so a message matching a button on it is still kept. Written against the store as the write lands, so two messages said without a render between them are both kept and one said twice is kept once.
- **A phrase with its choices made is the phrase it came from**, not a new one — `isFilledFrom` in `core/phrases.ts`, asked by `keepingSaid` and by `keepSaid` before it makes an id. "I want the red one" is `I want the {['red', 'blue']} one` said, and choosing it off the board counted that phrase already; kept as new, every combination anybody chose became a phrase of its own beside the one it came from. One of each slot's options, its label where it was left unchosen, and anything at all in a blank, matched against the phrase as `compose` writes it so the spacing and the dropped full stop agree; case and runs of spaces do not count. A message that says more than the phrase is a message of its own, and is kept.
- **Filed under the tab showing** by `keepSaid` in `talk/talk.tsx`, which passes the category to the board's `keepSaid` as `into` — Library and the records pass none. Only a message Library did not have: what typing finds comes from Library whichever tab is showing, so a phrase found that way and said is not something the tab was asked to hold, and choosing a phrase off the board files nothing either.
- **Said with Speak and save, a phrase is counted too**, and pointed at the same way: the phrase it saved, or the phrase that says the words where Save refused them (`handleSpeak` in `talk.tsx`). It was saved and never counted, so under Recently used and Most used it sat behind every phrase with any use — the end of the board — and a question answered in edit mode is answered that way. Not a button on the emergency bar, which is counted nowhere.
- **Shown where it went.** Kept and never seen, a new message was a phrase lost: used once, it sits after every phrase used more under Most used — below the first screen of a board in use — and at the very end of a hand arrangement, so it read as not kept at all. So the board points at it (`pointing`, marked and scrolled to) as it does a phrase just saved — **once the words have ended**, because the board takes its new order then and a phrase pointed at sooner would move after the scroll, **and once the box has stopped searching**: while the message is in the box the grid shows what typing finds, and a scroll made then would be lost the moment it was cleared (`pointWhenSaid`, `pointWhenShown` in `talk.tsx`). A copy has nothing said to wait for.
- **When**: Speak, a copy the clipboard accepted, and a phrase said on the spot in auto-speak. Not a cell off Translations, which is in another language and kept there already; not the emergency bar; not the apology said while an answer is written.
- **Counted as used the moment it is kept**, so it comes first among what typing finds and first in Library under *Recently used* — which is the Sent tab's newest-first, from the next look on. A message that is a phrase already is **not** counted again: choosing it off the board counted it, and a second count for saying it would make every phrase composed and then spoken count double against one said in auto-speak.
- **It is a phrase like any other**, and that is the privacy cost, said plainly wherever the app says what leaves the device. The Sent list was never in a backup or a snapshot; a phrase is in both, and goes to Anthropic with the board when suggested answers are asked for. The guide's *Saying something again*, the privacy policy's *What Peri stores* and the suggested-answers row in Settings all say so. Deleting it in edit mode takes it out of all of them.
- **A board from before brings its list in once**, as the board opens — `withSentKept` in `talk/use-board.ts`, reading `peri_sent` through `loadSent`. Oldest first, so the phrases stand in the order they were said; nothing is counted, since the list kept no times. The key goes only once the store holding them has been kept, so a device refusing writes tries again next time, and nothing is brought in twice. `SENT_KEY` stays in `RESETTABLE_KEYS` for a list nothing has opened since.
- **This was a major release**: a tab was taken away.
